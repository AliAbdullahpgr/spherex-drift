The packet describes the deployed prototype, including the difference between WISE
observing dates and SPHEREx combined-date mosaics. It does not claim a new planet,
new astronomical discovery, confirmed chemical detection or precision photometry.

The separate Project Demo URL must point to the short video or slide deck. This
packet does not supply a demo URL, modify the Space Apps account, confirm team
eligibility or submit the project for judging. Check the required fields and the
event's current instructions on the submission form before the final submission.
